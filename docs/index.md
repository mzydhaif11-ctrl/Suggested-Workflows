# قاعدة المعرفة

أضف إلى هذا المجلد ملفات Markdown أو TXT التي تريد إدخالها في قاعدة المعرفة
والبحث فيها عبر ChromaDB. تُفهرس ملفات الوثائق تلقائيًا، بينما يُستثنى هذا
الملف `index.md` من الفهرسة.

استخدم فقط ملفات مصرحًا بمشاركتها مع التطبيق. لا تضع أسرارًا أو بيانات شخصية
أو وثائق سرية في المستودع؛ فملفات هذا المجلد قد تُضاف إلى فهرس البحث المحلي.
