# 🔌 دليل واجهات برمجة التطبيقات (API Reference)

يوثق هذا الملف جميع نقاط النهاية (Endpoints) المتوفرة في واجهة برمجة التطبيقات لمنصة **موجة البيان (Mowjh Al-Bayan)**. يمكن تجربة كافة المسارات بشكل تفاعلي عبر واجهة Swagger المدمجة على المسار `/docs`.

---

## 1. فحص جاهزية الخادم (Health Check)
يُستخدم للتحقق من أن التطبيق يعمل وفي وضع الجاهزية لاستقبال الطلبات.

* **المسار (Path):** `/`
* **البروتوكول (Method):** `GET`
* **نوع الاستجابة:** `application/json`

### استجابة ناجحة (Status 200 OK):
```json
{
  "status": "ok"
}
