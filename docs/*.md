# 🌊 منصة موجة البيان (Mowjh Al-Bayan API)

## 📌 نظرة عامة
**موجة البيان** هي منصة دعم تقني متقدمة تعتمد على الذكاء الاصطناعي (AI) وتعمل بنظام **RAG** (Retrieval-Augmented Generation). تهدف المنصة إلى معالجة استفسارات المستخدمين وتقديم إجابات دقيقة وموثوقة بناءً على قاعدة معرفية مخصصة.

---

## 🛠️ البنية التحتية والتقنيات المستخدمة (Infrastructure)
تم بناء المنصة باستخدام أحدث التقنيات لضمان السرعة والموثوقية:
* **إطار العمل (Backend):** `FastAPI` (بايثون).
* **نموذج الذكاء الاصطناعي (LLM):** `Gemini 1.5 Flash` و `Gemini Embedding 001` من Google.
* **قاعدة البيانات المتجهية (Vector DB):** `Qdrant` للبحث الدلالي السريع.
* **بيئة الاستضافة والنشر (Deployment):** `Render` (عبر ملف `render.yaml`).
* **واجهات المستخدم (UI):** قوالب HTML مدمجة باستخدام `Jinja2` ومصممة بـ `Tailwind CSS`.

---
