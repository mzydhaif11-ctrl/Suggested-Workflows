# 🌊 موجة البيان | Mowjn AI-Bayan

مساعد عربي محلي للبحث في الوثائق والإجابة عنها باستخدام **ChromaDB للاسترجاع**
و**Ollama للتوليد**. النموذج اللغوي لا يدرّب هنا؛ النظام يسترجع مقاطع من
الوثائق ثم يمررها إلى النموذج لصياغة جواب قابل للمراجعة.

## البنية

- `vector_store.py`: تقسيم الوثائق وتضمينها وفهرستها في مجموعة Chroma دائمة.
- `rag_engine.py`: استرجاع المقاطع دلاليًا، مع بحث بالكلمات المفتاحية عند تعذر البحث الدلالي.
- `llm_client.py`: عميل محلي لواجهة Ollama `/api/chat`.
- `adaptive_memory_engine.py`: ذاكرة محادثة مستقلة في مجموعة Chroma منفصلة.
- `server.py`: واجهة FastAPI التي تنسق الاسترجاع والتوليد.
- `ingest.py`: فهرسة وثائق Markdown وTXT.

## المتطلبات

- Python 3.10 أو أحدث.
- Ollama مثبت ويعمل محليًا.
- نموذج ALLaM مثبت في Ollama. استخدم `ollama list` لنسخ الاسم كما يظهر لديك.
- اتصال أولي بالإنترنت لتنزيل الاعتماديات ونموذج التضمين. بعد تخزين النماذج محليًا
  يمكن تجهيز بيئة تعمل دون اتصال، لكن ذلك يحتاج إعداد كاش النماذج مسبقًا.

## الإعداد والتشغيل

من مجلد المستودع:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
ollama list
```

عدّل `.env` واجعل `OLLAMA_MODEL` مطابقًا تمامًا لاسم النموذج الظاهر في
`ollama list`. إذا لم يكن مثبتًا بعد، نزّله باستخدام أمر Ollama المناسب للاسم
المتاح في جهازك.

أضف الوثائق المصرح باستخدامها إلى `docs/` بصيغتي `.md` أو `.txt`، ثم أنشئ
الفهرس:

```powershell
python ingest.py --rebuild
```

يشغّل `--rebuild` إعادة بناء مجموعة المعرفة. بعد ذلك شغّل التطبيق:

```powershell
python main.py
```

افتح [http://127.0.0.1:8000](http://127.0.0.1:8000). واجهة API متاحة عبر
[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

## إعدادات مهمة

راجع `.env.example` للقيم الافتراضية. أهمها:

- `LLM_MODE=ollama`: إجابة مولدة بالنموذج المحلي. استخدم `none` لعرض نتائج البحث فقط.
- `OLLAMA_BASE_URL` و`OLLAMA_MODEL`: عنوان Ollama واسم النموذج.
- `EMBEDDING_MODEL`: نموذج التضمين المستخدم للفهرسة والبحث. يجب إعادة بناء الفهرس
  عند تغييره؛ لا تخلط متجهات نماذج مختلفة في المجموعة نفسها.
- `CHROMA_PERSIST_DIR` و`CHROMA_COLLECTION`: تخزين قاعدة الوثائق.
- `MEMORY_PERSIST_DIR` و`MEMORY_COLLECTION`: تخزين ذاكرة المحادثة المنفصلة.
- `TELEMETRY_ENDPOINT`: اتركه فارغًا لإيقاف المزامنة المجتمعية الخارجية.

## الخصوصية وحدود الاستخدام

تُحفظ قاعدة المعرفة والذاكرة على القرص المحلي، ويستقبل Ollama الطلب محليًا.
لكن تنزيل الاعتماديات ونماذج التضمين لأول مرة يحتاج اتصالًا خارجيًا. كما أن
التليمترية قد ترسل إحصاءات عند إعداد نقطة نهاية خارجية ووجود موافقة محفوظة.
بيانات Chroma والذاكرة وملف `.env` مستبعدة من Git. لا تضع وثائق سرية في
المستودع أو تشارك مجلدات التخزين.

الإجابات مولدة آليًا؛ راجع المصادر والوثيقة الأصلية قبل اعتماد أي قرار رسمي.
الخطوة التالية قبل الاستخدام المؤسسي هي إضافة مجموعة تقييم موثقة، واختبار
الاستشهادات والدقة، وتحديد الصلاحيات والنسخ الاحتياطي.
