## 🌊 عن المنصة
منصة دعم فني ذكية مبنية على تقنيات استرجاع البيانات والتأصيل (RAG) لنماذج **Google Gemini API**، ومربوطة بقاعدة بيانات المتجهات السحابية **Qdrant** لتقديم إجابات موثوقة ومطابقة للتوثيق المعتمد.

---

## 🚀 المكونات والتقنيات المستخدمة
* **Vector Database:** قاعدة بيانات **Qdrant** لتخزين واسترجاع السياق بسرعة فائقة.
* **LLM Engine:** نماذج **Gemini** الموثقة بالوثائق الرسمية لمنع الهلوسة.
* **Backend:** خادم **FastAPI** لتوفير واجهات API سريعة للمحادثة والبحث.
* **Frontend:** واجهة محادثة عصرية ومتجاوبة باللغة العربية مع إسناد المصادر.
